# Alvo4SAT v1.1 — GitHub Pages

Conteúdo do pacote extraído: a versão padrão fica na raiz e a versão Pro em `/pro/`.

## Instalação no repositório `iatseixas/Alvo4SAT-v1.1`

1. Envie **todo o conteúdo desta pasta** ao ramo `main` usando Add file > Upload files.
2. Em Settings > Pages, selecione Deploy from a branch, ramo `main`, pasta `/(root)`, depois Save.
3. Abra https://iatseixas.github.io/Alvo4SAT-v1.1/ e https://iatseixas.github.io/Alvo4SAT-v1.1/pro/.
4. No Safari do iPhone, selecione Compartilhar > Adicionar à Tela de Início.

Os dois PWAs usam manifestos e service workers independentes. Esta documentação não confirma que o Pages já esteja ativado ou publicado.
