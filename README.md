# Alvo4SAT-v1.1 — PWA

Versão padrão do Analisador de Alvo 4 Cores padrão SAT/ANP/PF.

## Diferença para a versão Pro

As ações **Salvar Alvo** e **Laudo Anexo II** permanecem visíveis, porém exibem um aviso informando que o download está disponível somente no **Alvo4SAT-Pro**. O aviso oferece links provisórios para a Google Play Store e Apple App Store.

## Instalação

Publique a pasta `PWA/site` por HTTPS. No Android/Chrome, use **Instalar aplicativo**. No iPhone/Safari, use **Compartilhar > Adicionar à Tela de Início**.


## Revisão r3

Corrigido o bloqueio dos botões **Salvar Alvo** e **Laudo Anexo II** na versão padrão. Ao tocar neles, é exibido o aviso da versão Alvo4SAT-Pro com acesso provisório às lojas.
