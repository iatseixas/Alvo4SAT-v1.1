# Alvo4SAT-ProV1.1 — PWA

Versão Pro do Analisador de Alvo 4 Cores padrão SAT/ANP/PF.

## Recursos Pro

- Salvar/baixar o alvo da prova.
- Gerar e salvar o Laudo Anexo II.
- Mantém os demais recursos da versão 1.1.

## Instalação

Publique a pasta `PWA/site` por HTTPS. No Android/Chrome, use **Instalar aplicativo**. No iPhone/Safari, use **Compartilhar > Adicionar à Tela de Início**.
